# BREACH

### Realistic Tactical FPS | Unity 6 | C#

## About the Project

BREACH is an independent game development project focused on building a tactical first-person shooter using Unity 6 and C#.

The project explores game programming, artificial intelligence, gameplay systems, and software development.

## Current Features

* First-person movement and camera control
* Weapon and shooting mechanics
* Reloading and ammunition systems
* AI bots with different behaviour states
* Offline matches
* Attackers and Defenders teams
* Round-based gameplay
* Kill/death tracking and scoreboard

## Technologies

* Unity 6
* C#
* Git
* GitHub

## Development Goals

* Improve AI behaviour
* Develop gameplay systems
* Improve graphics and environments
* Build additional game mechanics
