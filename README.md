# BREACH

**A realistic tactical competitive FPS built with Unity 6 and C#**

BREACH is an independent game-development project exploring the engineering behind tactical first-person shooters. The project focuses on responsive gameplay systems, AI behaviour, round-based match logic, and maintainable software architecture.

> **Project status:** In development. This repository currently contains project documentation and repository configuration. The Unity source project is maintained separately and has not yet been published here.

## Project goals

- Build a tactical FPS prototype with clear, reliable gameplay systems.
- Explore finite-state AI and navigation with Unity NavMesh.
- Implement round-based competitive match flow.
- Practice clean C# architecture, version control, and technical documentation.

## Implemented prototype features

These exist in the local Unity prototype. They are not in this repository yet.

- First-person player movement and camera control.
- Weapon firing, recoil, ammunition, and reload mechanics.
- Crosshair and gameplay HUD.
- Practice targets with configurable damage.
- AI bots with navigation and behaviour states, including patrol, investigate, chase, engage, and search.
- Offline Attackers vs. Defenders matches.
- Round timer, elimination and timeout outcomes.
- Kill/death tracking and an in-game scoreboard.
- Procedurally generated practice environment and map layout.
